# CoolMag Media Center — Web Edition

This is the browser edition of CoolMag Media Center. It is a static HTML, CSS, and JavaScript site intended for GitHub Pages.

## Included

- Radio Browser station search by country, station-origin display, current weather, and radio favorites.
- IPTV-org playlist browser for worldwide, India, news, music, and sports channels, with channel favorites.
- Links to official news publishers, including BBC, The Hindu, Sikkim Express, and Daily Thanthi.
- Favorites already published in the repository are loaded into the web edition; browser-specific favorites are stored in that browser's local storage.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/docs**, then save. The project page will be available at:

`https://suppuone.github.io/RADIOtv/`

The repository and website are public. Never put a GitHub access token or other secret in these files.

## Stream availability

The app links to streams hosted by station and playlist providers; it does not store or retransmit their media. Browser support, stream availability, and broadcaster restrictions vary. Some radio or TV streams may not play in every browser.
